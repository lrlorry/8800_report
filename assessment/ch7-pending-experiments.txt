1. 自适应预算的实际总耗时与回本（最高优先级）
================================================
目的：目前 selected-arm 平均 QPS 与回本属于离线估算；补直接测量，
验证包含校准后，短任务和长任务分别是否真正省时。

待办：
[ ] 固定同一训练状态、query split、构建参数和计时边界。
[ ] 先做四个单元：OpenAI-1536/128、OpenAI-3072/128、arXiv/128、
    BGE/512，分别覆盖明显收益、负收益和相对 alpha=64 接近持平。
[ ] 比较 fixed alpha=64、fixed alpha=100、自适应 S=128。
[ ] 每次自适应试验只在开始校准一次，随后执行 N=1/10/100/500 个
    batch；直接测 T_total = T_calibration + sum(T_search)。
[ ] 校准含 reference search、agreement 检查及实际必要的数据准备；
    明确索引加载、一次性调度校准、预热是否计入，并统一比较口径。
    主机计时需等待对应 GPU 工作完成。
[ ] 多轮独立校准，交替策略运行顺序，记录 seed、所选 alpha、每个
    batch 的实际耗时及总耗时。沿用实际查询数，不强行把 499 写成 500。
[ ] 校准查询与持出查询分离；GT 只用于事后评价。保存每轮持出 recall
    和相对最佳已测预算的损失，不根据持出结果调参再称独立验证。
[ ] 若循环复用现有持出查询，明确是固定查询池的重复执行；不声称是
    新的独立查询流或工作负载漂移实验。

交付：每轮原始 JSON/JSONL、运行清单、总耗时随 batch 数变化的图、
相对两种固定预算的实测回本与质量结果。允许出现无回本或收益缩小；
不得将估计值改名为实测值。
入口参考：JHQ_GPU/examples/demo_jhq_budget_arms_v69.cu、
experiments/adc_v69/run_budget_v69.sh。现有脚本不是此新增实验的完整
实现；恢复时先补测量和日志接口，再运行，保留历史输出。

2. Vogue 跨进程结果差异的受控诊断（第二优先级）
================================================
目的：已有记录在 probe/primary 相同的用例中，最终 recall 为
0.9642/0.9644；同一 baseline binary 的不同进程也出现该差异。
定位最早发生分歧的边界，不预先指定根因。

待办：
[ ] 固定并记录同一训练状态、输入、参数、二进制和源码身份。
[ ] 先复现已有 G=1、batch=8、完整 1,000 查询的受控用例。
[ ] v65/v69 各启动多个独立进程；保留同一 binary 内的重复进程对照。
[ ] 保存输入/训练状态及相关中间表示的身份；逐层比较 query rotation、
    probe、primary 候选、residual scores、最终 ID/顺序/距离。
[ ] 检查并列与舍入；若用 CPU 参考选择器，应针对同一份已记录分数
    和约定的 tie key，不混同原空间 exact kNN。

交付：逐进程结果、差异查询列表、可取得的 dump 及哈希、最早分歧
阶段的证据。若有限诊断仍未定位，明确记录未知，不无限扩展调试范围。
入口参考：JHQ_GPU/experiments/practical_opt/v69_results/ 与
experiments/practical_opt/v69_run.sh。旧 dump 哈希记录不代替新增 dump。

另行并发核验（撰写 5.5 时发现，与 Vogue 根因分开）
-------------------------------------------------

    读取；CUDA 不为 volatile 提供原子读取保证。核查并采用设备作用域
    的原子读取方案，再重跑同 G 的独立界/共享界输出对照和计时。
[ ] 将修订前后结果分别归档。当前 48 组通过记录支持被测构建中的
    实测一致性，不替代并发内存模型证明；目前未修改实现或执行复验。
