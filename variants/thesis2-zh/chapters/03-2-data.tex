OpenAI／BGE／Stella 准备阶段删除非有限行，并使用
\[
 x\leftarrow x/\|x\|\quad(\|x\|>10^{-12}).
\]
种子 42 用于无放回抽样。Stella 使用 999 个语料内查询，替代原有 65 个查询的基准；没有相关性标签。OpenAI 检查覆盖全部查询和 10,299 个基础行，支持行序对齐，但未按原始 ID 连接（\cref{sec:7-precision,sec:7-2}）。

各方法共享导出的查询／GT 文件。对 FP32 向量进行分块穷举平方 L2 搜索，维护 GT top-$k$，包括并列：
\begin{equation}
\Recall@k=\frac{1}{|\mathcal Q|k}
\sum_{q\in\mathcal Q}|\mathcal R_k(q)\cap\mathcal T_k(q)|.
\label{eq:3-recall}
\end{equation}
这里 $\mathcal T_k$ 是存储 GT 的前缀，$\mathcal R_k$ 是返回 ID 集合。GT 宽度在 Vogue／arXiv 上为 100，其余为 20；只计前十项。重复 ID 不获得额外命中。越界、重复和重复调用检查分别进行。

JHQ 使用 $M=d/8$、$B=B_r=8$、八次粗量化迭代和 100,000 行残差训练数据。参数扫描重新载入／编码；冷构建重新拟合。训练使用数据库行。\[
 \begin{aligned}
 \mathcal Q_{\rm cal}&=\{q_i:i\bmod2=0\},&
 \mathcal Q_{\rm hold}&=\{q_i:i\bmod2=1\},\\
 (|\mathcal Q_{\rm cal}|,|\mathcal Q_{\rm hold}|)
 &=\begin{cases}(500,499),&\text{Stella},\\(500,500),&\text{otherwise}.\end{cases}
 \end{aligned}
 \]
每个单元对大小为 32、64、128 的带种子子样本各抽取 64 次；FULL 使用全部 500 个校准查询。标签用于评估 oracle 与留出集；一致性只使用输出（\cref{sec:6-2,sec:a-budget-contract}）。
