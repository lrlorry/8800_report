\subsection{计时与校准约定}
\label{sec:a-e1-protocol}
评测配置显式启用十六 lane 精排及自动扫描调度，在单 block 与 2／4／8 组之间选择，多组时启用共享界；库默认使用标量精排及单 block。可选配额式近似选择器关闭。一次性调度器校准不计入稳态搜索时间，下列三项分别为伪查询收集、首次调用及重复调用中位数的调度器启动耗时：
\[
 T_{\rm gather}\in[0.81,7.04]\,\mathrm{ms},\quad
 T_{\rm first}\in[6.00,27.77]\,\mathrm{ms},\quad
 \operatorname{median}(T_{\rm repeat})\in[2.72,18.13]\,\mathrm{ms}.
\]

主比较中，JHQ 每个变体／轮次预热一次，基线起初预热三次。驱动即时（just-in-time，JIT）编译和 JHQ CUDA Graph 捕获均在计时前完成；后者记录 GPU 操作，供后续重复执行。慢基线配置依据预热耗时估计，使用较少的计时调用。重复调用间的 ID 顺序变化可能包括并列重排，本身不排除测点；这不同于单次结果内部含有重复 ID。JHQ 没有同样的重复调用诊断标记。

打包载入比较为每个变体保留一项汇总计时。采样预算表同时报告 64 个样本的所选预算中位数与平均质量；平均召回由打印的最佳召回减去已记录平均损失重建，因此两项统计未必对应同一个固定预算。

\label{sec:a-budget-contract}
\label{sec:a-supplement}
\label{sec:a-t4-t5}
预算实验中，每个固定预算预热一次、计时三次。校准时间包括参考搜索、试验预算下的搜索，以及在主机上比较这些搜索的结果（$O(Sk^2)$）；不包括收集样本查询、一次性的调度器校准和图捕获。预热遍历全部查询，但其输出不参与预算选择，校准过程也不使用 GT。所选预算 QPS 使用固定预算计时，直接复用测试见 \cref{sec:6-5}。对排序后的 64 个召回损失，报告分位数采用
\[
 L_{95}=L^{\rm sorted}_{\lfloor0.95(64-1)\rfloor}
       =L^{\rm sorted}_{59}\qquad\text{(zero-based)}.
\]
