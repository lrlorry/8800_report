\subsection{Stored bytes and allocated bytes}

With one-byte primary subspace codes, resident row and offset bytes are
\begin{equation}
 S_{\rm rows}=N\left(M+\left\lceil\frac{dB_r}{8}\right\rceil+8\right),
 \qquad S_{\rm offsets}=4(n_{\rm list}+1).
 \label{eq:4-row-storage}
\end{equation}
$S_{\rm ID}+S_{\rm correction}=4N+4N=8N$ bytes. At $M=d/8$, $B_r=8$, codes take $9d/8$ bytes, 12.5\% above SQ8. Graph-free does not imply smaller than int8.

At $d_g=32$, CAGRA row bytes are $d+4d_g$. Stella's JHQ payload (19.20\,GiB) nearly equals CAGRA int8's 19,656\,MiB, with different scopes. JHQ is graph-free and changes residual reads via $\alpha$, not stored bytes.

Basic model storage is
\[
 S_{\rm model}
 =4d^2+4MKD_s+4MK_r+4n_{\rm list}(d+1)
 \quad\text{bytes}.
\]
Derived arrays are additional. Workspace holds two $[b_{\rm cap},d]$ query matrices, centroid scores, LUTs, probes and survivors. Optional residual LUTs add $4b_{\rm cap}dK_r$ bytes; defaults score directly. Group capacity remains about 93.8\,MiB at 128 probes, even without grouped execution (\cref{eq:5-group-workspace}).

Input is caller-owned. Separate staging/order storage is
\[
 S_{\rm pinned}=4n_ba_{\rm in}d,\qquad
 S_{\rm order}=S_{\rm inverse}=4N.
\]
Assignment scratch is freed before gather (\cref{eq:4-staging-rows,eq:4-assignment-scratch}).

\subsection{Reuse, recovery and invalidation}

Caches save models but omit code version/full-data hashing from the key. Changed code/data need invalidation and provenance. Sweeps share states; cold builds refit. Similar recall does not prove identical models.

Cache hits still pay QR, warm-up, model upload and add. Stella's 6.67\,s add includes initial workspace, excluding schedule calibration and search warm-up; it is not restart time.

$\alpha$ changes need no retraining. Workspace grows before capture; changes to batch, survivors, probes, lanes, groups or bounds recapture the graph. Calibration may bypass capture. Index-owned buffers are reused, then released.
