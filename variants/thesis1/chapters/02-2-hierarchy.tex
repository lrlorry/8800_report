IVF groups vectors into coarse-centroid lists. A query chooses $n_{\rm probe}$ lists,
producing a routed universe $U(q)$ of $n_c$ candidates. Visiting fewer lists
reduces access work but can exclude a true neighbour before any fine scoring.
Choosing lists and ranking database vectors are separate steps.

PQ learns one codebook per coordinate subspace \cite{pq}. ADC keeps $q$ unquantised:
\begin{equation}
 \|q-\widehat x\|^2=\sum_{m=0}^{M-1}\|q_m-\mathcal C_m[z_m]\|^2.
 \label{eq:2-adc}
\end{equation}
A query table replaces coordinate scoring with lookups. Products across subspaces do not imply Cartesian structure within a learned subcodebook; Chapter 5 needs the latter.

The residual definitions differ:
\[
 r_{\rm IVF\text{-}PQ}=x-\mu_{\ell(x)},\qquad
 r_{\rm JHQ}=\Pi x-\widehat p(x).
\]
JHQ reconstruction must not add a centroid the encoder never removed. Candidate expansion/refinement is established \cite{johnson_gpu,faiss_refine}.

With $|U(q)|\geq k$ and $c=\max\{k,\lceil\alpha k\rceil\}$,
\begin{equation}
 \mathcal R_\alpha(q)\subseteq C_\alpha(q)\subseteq U(q)\subseteq\mathcal X.
 \label{eq:2-cascade}
\end{equation}
For GT set $\mathcal T_k$, set inclusion gives
\[
 |\mathcal R_\alpha\cap\mathcal T_k|
 \leq |C_\alpha\cap\mathcal T_k|
 \leq |U\cap\mathcal T_k|.
\]
Refinement cannot recover excluded IDs. Isolating each loss still needs fixed-universe counterfactual scoring.
