For stable-ID database $\mathcal X\subset\mathbb R^d$, exact neighbours minimise
\begin{equation}
 \rawdist(q,x)=\|q-x\|_2^2.
 \label{eq:2-raw}
\end{equation}
Recall@10 measures overlap with stored GT, including its tie choices (\cref{eq:3-recall}), rather than a worst-case distance ratio.

We measure QPS, batch latency, build cost and memory. Batch timing does not measure concurrent-request tails; memory figures have different boundaries. Chapter 3 defines them.
