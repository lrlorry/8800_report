\paragraph{JHQ-GPU.}
All E1 points use $B=B_r=8$, $M=d/8$, $k=10$ and batch 1,000.
Vogue uses 4,096 IVF lists; the other three use 8,192.
Vogue observes probes 16/\allowbreak{}32/\allowbreak{}64/\allowbreak{}96/\allowbreak{}128/\allowbreak{}192/\allowbreak{}256/\allowbreak{}384/\allowbreak{}512 and
$\alpha\in\{16,32,64,128\}$ over 27 tuples. ArXiv adds probe 1,024
and uses $\alpha\in\{25,50,100,200\}$ over 29 tuples.
Both OpenAI grids use probes 32/\allowbreak{}64/\allowbreak{}128/\allowbreak{}256/\allowbreak{}512/\allowbreak{}1,024;
their observed multipliers are respectively
$\{4,8,16,32,64,128,256,512\}$ and
$\{2,4,8,16,32,64,128,256\}$, over 37 and 39 tuples.
The reported scheduled path uses four groups on Vogue and one block
elsewhere. OpenAI uses TF32 rotation/centroid GEMMs in historical v69;
the v72 FP32 sensitivity is a separate family (\cref{sec:7-precision}).

\paragraph{CAGRA fp32 and int8.}
Each representation has 64 points per dataset: graph degrees 32/\allowbreak{}64,
intermediate degree 128, \texttt{ivf\_pq} construction,
\texttt{itopk\_size} in 32/\allowbreak{}64/\allowbreak{}96/\allowbreak{}128/\allowbreak{}192/\allowbreak{}256/\allowbreak{}384/\allowbreak{}512 and search width
1/\allowbreak{}2/\allowbreak{}4/\allowbreak{}8. Int8 records quantile 0.99 for dataset scaling and includes
query quantisation in the host search boundary.

\paragraph{IVF-PQ.}
Eight-bit subcodes use 192/\allowbreak{}384/\allowbreak{}768-byte codes at dimension 768,
and 384/\allowbreak{}768/\allowbreak{}1,536-byte codes on OpenAI. Each length has fp16/fp32
lookup tables and probes 16/\allowbreak{}32/\allowbreak{}64/\allowbreak{}96/\allowbreak{}128/\allowbreak{}192/\allowbreak{}256/\allowbreak{}384/\allowbreak{}512:
54 points per dataset. The recorded refinement ratio is one and list
counts match JHQ. Code lengths and memory budgets differ.

\paragraph{IVF-RaBitQ and brute force.}
RaBitQ sweeps 4/8/9 bits and probes 16/\allowbreak{}32/\allowbreak{}64/\allowbreak{}96/\allowbreak{}128/\allowbreak{}192/\allowbreak{}256/\allowbreak{}384/\allowbreak{}512/\allowbreak{}768/\allowbreak{}1,024. Modes are LUT16/LUT32/QUANT4/QUANT8 except OpenAI-3072 omits LUT16. OpenAI adds 4,096-list indexes to default 8,192-list coverage; exact combinations remain in the registry. Each dataset has one FP32 squared-L2 brute-force point. Missing coverage is not failure.

\paragraph{Auxiliary grids.}
LUT sweeps six datasets, four probe counts (8/32/128/512) and $\glut\in\{1,2,4,8\}$ at $\alpha=100$: 24 cells, 96 arms.
Budget evaluation uses probes 128/\allowbreak{}512 and
$A=(200,100,64,32,16,8,4,2)$ on the same six datasets, with 64 draws
at each $S\in\{32,64,128\}$ and $\epsilon=1$. FULL separately uses
all 500 calibration queries. Held-out counts are 500, or 499 for
Stella.  Boundaries are specified in
\cref{sec:a-budget-contract,sec:a-supplement}.

\subsection{Contemporaneous precision anchors}
\label{sec:b-precision-anchors}

T1 remeasures JHQ and baselines near recall 0.97 in one session with E1 pools.
