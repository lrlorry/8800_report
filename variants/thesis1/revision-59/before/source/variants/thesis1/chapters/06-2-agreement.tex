Let $\mathcal R_\alpha(q)$ be the set of $k$ valid, unique database IDs
returned at budget $\alpha$ on a fixed index. Define
$\mathcal R_{\rm ref}(q)=\mathcal R_{\alpha_{\rm ref}}(q)$. The descending grid is
\begin{equation}
 A=(200,100,64,32,16,8,4,2),\qquad \alpha_{\rm ref}=A[0]=200.
 \label{eq:6-grid}
\end{equation}
For $S$ calibration queries $\mathcal Q_S$, define
\begin{equation}
 \begin{aligned}
 D_S(\alpha)
 &=\sum_{q\in\mathcal Q_S}
   \left(k-|\mathcal R_\alpha(q)\cap\mathcal R_{\rm ref}(q)|\right)\\
 &=\frac12\sum_{q\in\mathcal Q_S}
   |\mathcal R_\alpha(q)\triangle\mathcal R_{\rm ref}(q)|.
 \end{aligned}
 \label{eq:6-agreement}
\end{equation}
A budget is accepted iff $D_S(\alpha)\leq\epsilon$, with $\epsilon=1$:
one missing reference ID across the sample, independent of result order
or reported distances. The finite-grid objective is

\begin{equation}
 \widehat\alpha=\min\{\alpha\in A:D_S(\alpha)\leq\epsilon\}.
 \label{eq:6-selection-objective}
\end{equation}
The reference supplies a nonempty fallback. The objective minimises an
accepted multiplier; \cref{sec:6-3} states when bisection solves it exactly.

At $k=10$, the normalised allowance $\epsilon/(Sk)$ is 0.003125,
0.0015625 and 0.00078125 for $S=32,64,128$, and 0.0002 at $S=500$.
Larger $S$ changes coverage and strictness. Disjoint held-out queries assess draws from one finite calibration pool (\cref{sec:7-5}).

\subsection{What agreement controls}

Under \Cref{prop:6-monotonicity}, disagreement counts reference answers
excluded by primary screening:
\begin{equation}
 D_S(\alpha)=\sum_{q\in\mathcal Q_S}
       |\mathcal R_{\rm ref}(q)\setminus C_\alpha(q)|.
 \label{eq:6-reference-coverage}
\end{equation}
For valid $k$-element outputs, each missing reference ID costs at most
one GT hit. On the same sample,
\begin{equation}
 \begin{aligned}
 r_{\mathcal Q_S}(\alpha)
 &\geq r_{\mathcal Q_S}({\rm ref})-\frac{D_S(\alpha)}{Sk},\\
 D_S(\alpha)\leq\epsilon
 &\implies r_{\mathcal Q_S}(\alpha)
       \geq r_{\mathcal Q_S}({\rm ref})-\frac{\epsilon}{Sk}.
 \end{aligned}
 \label{eq:6-relative-recall}
\end{equation}
\paragraph{Scope.}
This is a sample-local bound relative to the reference. GT evaluation
measures the reference's remaining error (\cref{sec:7-recall-attribution}).

\subsection{Sampling resolution and ordered testing}

Let $H_S$ count queries with any missing reference ID. Since $H_S\leq D_S$,
acceptance implies $H_S\leq1$. For a prespecified budget and i.i.d.
queries, the one-sided 95\% exact binomial upper limit after one event solves
\cite{nist_binomial}
\begin{equation}
 (1-u)^S+Su(1-u)^{S-1}=0.05.
 \label{eq:6-binomial-limit}
\end{equation}
The query-event limits are 0.03652 at $S=128$ and 0.009452 at 500.
Treating all $Sk$ result indicators as homogeneous independent Bernoulli
trials is stronger: the corresponding limits are 0.003701 and 0.0009484,
approximately $4.74/(Sk)$. Query i.i.d. alone does not justify dividing
the query-event limit by $k$; neither model certifies repeated subsamples
of this fixed pool.

Monotone disagreement makes accepted indices a prefix. Valid per-arm tests can then use fixed-sequence error control \cite{learn_then_test}. Our one-slot threshold tests stability; it does not certify GT risk.

\paragraph{A finite-pool extension.}
Assume each query has fixed $X_q(\alpha)$ at the intended execution regime, independent of subset membership/position. For pool size $N_{\rm cal}$ and counts $n_j=|\{q:X_q=j\}|$, uniform sampling without replacement accepts only all-zero samples or one single-count query \cite{nist_hypergeometric}:
\begin{equation}
 \Pr\{D_S(\alpha)\leq1\}
 =\frac{\binom{n_0}{S}+n_1\binom{n_0}{S-1}}{\binom{N_{\rm cal}}{S}}.
 \label{eq:6-finite-pool}
\end{equation}
Out-of-range binomial coefficients are zero. Predicting GT risk also needs the grid acceptance structure and held-out fixed-arm quality. Recorded subset sums test count invariance (\cref{sec:7-budget-trace}).
