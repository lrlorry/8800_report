\subsection{Strict CPU reference for computed-score selection}
\label{sec:7-strict-selection}

T4 CPU-sorts GPU-produced primary scores under $(\primarydist,\mathrm{position})$. Its exporter follows scan layout/accumulation and matches returned valid scores bitwise. Source comparison confirms that the diagnostic version changes only export, relative to the table-sweep implementation. The 270 configurations cover Vogue/arXiv/OpenAI-3072, 1/8/128 probes, $\alpha\in\{4,100,200\}$, $\gscan\in\{0,1,2,4,8\}$ and both bound settings: 69,120 query instances (\cref{tab:7-strict-selection}).
