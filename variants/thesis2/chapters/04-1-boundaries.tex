Train fits models; add encodes/list-orders rows; search uses the completed index. Cache hits skip fitting, not encoding, so cold-build and cached-search costs differ.

Models hold rotation, codebooks and centroids; database state holds offsets, IDs, codes and corrections. Graphs reference reused query buffers.

One successful \texttt{add} fixes positions. Further adds are rejected; updates require rebuilding. Mutable/transactional publication is unimplemented.
