Primary screening changes coordinate work from $O(n_cd)$ to $O(cd)$. Lanes cooperate at the same budget.

\subsection{Reconstructed scoring and the query-only constant}

For $\gamma=2\langle\widehat p,\widehat r\rangle$, expand in real arithmetic:
\begin{align}
 \refineddist(q,x)
 &=\primarydist(q,x)+\|q'-\widehat r(x)\|_2^2+\gamma(x)
 \label{eq:5-refined-score}\\
 &=2\|q'\|_2^2+\|\widehat p+\widehat r\|_2^2-2\langle q',\widehat p+\widehat r\rangle\nonumber\\
 &=\|q'-\widehat p(x)-\widehat r(x)\|_2^2+\|q'\|_2^2.
 \label{eq:5-refined-constant}
\end{align}
The query constant preserves reconstructed-distance order \cite{jhq}.

Scalar scoring sums squared residual differences, then adds primary score/correction. Queries and fitting codebooks use shared memory.

\subsection{Final selection and the numerical boundary}

For at least $k$ finite valid survivors with unique IDs, each round computes
\[
 i^*=\arg\min_{i<c}(D_{H,i},\mathrm{ID}_i),\quad d^*=D_{H,i^*},\quad
 D_{H,i^*}\leftarrow+\infty
\]
using all slots and emits $(\mathrm{ID}_{i^*},d^*)$: exact retained-pool top-$k$, without thread quotas. Underfull pools may repeat the smallest valid ID at infinity; all-invalid pools return invalid IDs. Tests meet the finite-entry premise.

Primary ties use positions, final ties IDs. Exclusions/quantisation remain; lane FP32 association may move near ties.
