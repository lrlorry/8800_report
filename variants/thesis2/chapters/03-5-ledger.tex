\subsection{Timing and calibration conventions}
\label{sec:a-e1-protocol}
Warm-up reduces E1 call counts at 274 points; initial conversion/validation differs from steady-state timing. The 369 repeat-ID flags include tied reordering; 401 also counts cross-protocol differences. Flags alone exclude no points, and JHQ lacks the same flag.

\label{sec:a-budget-contract}
\label{sec:a-supplement}
\label{sec:a-t4-t5}
The campaign sets the 200-start grid explicitly. Fixed arms use one warm-up/three timed calls. Calibration times full searches and $O(Sk^2)$ host comparison, excluding gathering/scan calibration and bypassing graph capture. Warm-up visits every query without passing outputs/GT to agreement. Callers install the returned index with \texttt{set\_alpha(A[index])}; selected-arm rates reuse fixed-arm timing (\cref{sec:6-5}). For 64 sorted losses, the recorded quantile is
\[
 L_{95}=L^{\rm sorted}_{\lfloor0.95(64-1)\rfloor}
       =L^{\rm sorted}_{59}\qquad\text{(zero-based)}.
\]
