HNSW uses a hierarchy of proximity graphs to guide search from coarse
navigation to finer neighbourhoods \cite{hnsw}. GPU graph search must
also expose enough parallel work during traversal: SONG parallelises
graph search \cite{song}, while CAGRA adjusts connectivity and search
width \cite{cagra}. CAGRA's GPU-resident search makes it the graph
comparator here; both fp32 and quantised configurations are included.

DiskANN combines a graph index with SSD storage to search databases
larger than main memory \cite{diskann}. BANG uses host graphs to extend
GPU search capacity \cite{bang}. These systems move data across a
storage boundary; JHQ instead keeps its compressed hierarchy on the GPU.
The present comparison therefore tests resident execution rather than
SSD-backed search.
