Let $\mathcal R_\alpha(q)$ be the set of $k$ valid, unique database IDs
returned at budget $\alpha$ on a fixed index. Define
$\mathcal R_{\rm ref}(q)=\mathcal R_{\alpha_{\rm ref}}(q)$. The descending grid is
\begin{equation}
 A=(200,100,64,32,16,8,4,2),\qquad \alpha_{\rm ref}=A[0]=200.
 \label{eq:6-grid}
\end{equation}
For $S$ calibration queries $\mathcal Q_S$, define
\begin{equation}
 \begin{aligned}
 D_S(\alpha)
 &=\sum_{q\in\mathcal Q_S}
   \left(k-|\mathcal R_\alpha(q)\cap\mathcal R_{\rm ref}(q)|\right)\\
 &=\frac12\sum_{q\in\mathcal Q_S}
   |\mathcal R_\alpha(q)\triangle\mathcal R_{\rm ref}(q)|.
 \end{aligned}
 \label{eq:6-agreement}
\end{equation}
Accept iff $D_S(\alpha)\leq\epsilon=1$: at most one missing reference ID, ignoring order/distances. The finite-grid objective is

\begin{equation}
 \widehat\alpha=\min\{\alpha\in A:D_S(\alpha)\leq\epsilon\}.
 \label{eq:6-selection-objective}
\end{equation}
The reference is a fallback. \Cref{sec:6-3} gives the conditions for exact bisection.

At $k=10$, $\epsilon=1$ gives
\[
 \begin{array}{c|rrrr}S&32&64&128&500\\\hline
 \epsilon/(Sk)&0.003125&0.0015625&0.00078125&0.0002
 \end{array}
\]
Larger samples change coverage and strictness. Disjoint held-out queries evaluate draws from one finite pool (\cref{sec:7-5}).

\subsection{What agreement controls}

Under \Cref{prop:6-monotonicity}, disagreement counts reference answers
excluded by primary screening:
\begin{equation}
 D_S(\alpha)=\sum_{q\in\mathcal Q_S}
       |\mathcal R_{\rm ref}(q)\setminus C_\alpha(q)|.
 \label{eq:6-reference-coverage}
\end{equation}
For $k$-element outputs and GT set $\mathcal T_k$, set difference gives
\[
 |\mathcal R_{\rm ref}\cap\mathcal T_k|-|\mathcal R_\alpha\cap\mathcal T_k|
 \leq|\mathcal R_{\rm ref}\setminus\mathcal R_\alpha|.
\]
Summing and dividing by $Sk$ yields the relative bound. On the same sample,
\begin{equation}
 \begin{aligned}
 r_{\mathcal Q_S}(\alpha)
 &\geq r_{\mathcal Q_S}({\rm ref})-\frac{D_S(\alpha)}{Sk},\\
 D_S(\alpha)\leq\epsilon
 &\implies r_{\mathcal Q_S}(\alpha)
       \geq r_{\mathcal Q_S}({\rm ref})-\frac{\epsilon}{Sk}.
 \end{aligned}
 \label{eq:6-relative-recall}
\end{equation}
\paragraph{Scope.}
The bound is relative to the reference on this sample. GT evaluation
measures the reference's remaining error (\cref{sec:7-recall-attribution}).

\subsection{Sampling resolution and ordered testing}

Let $H_S$ count queries with any missing reference ID. Since $H_S\leq D_S$,
acceptance implies $H_S\leq1$. For a prespecified budget and i.i.d. queries, the one-event one-sided 95\% binomial limit solves \cite{nist_binomial}
\begin{equation}
 (1-u)^S+Su(1-u)^{S-1}=0.05.
 \label{eq:6-binomial-limit}
\end{equation}
The model-dependent resolutions are
\[
 \begin{array}{c|cc}
 &S=128&S=500\\\hline
 \text{i.i.d. query events}&0.03652&0.009452\\
 \text{i.i.d. homogeneous result slots}&0.003701&0.0009484
 \end{array}
\]
The stronger slot model gives approximately $4.74/(Sk)$. Query i.i.d. does not imply slot independence. Neither model certifies fixed-pool draws.

Monotonicity permits fixed-sequence control only with valid per-arm tests \cite{learn_then_test}. Our one-slot threshold measures agreement, not certified GT risk.

\paragraph{A finite-pool extension.}
Assume fixed per-query $X_q(\alpha)$, independent of subset/position within the execution regime. For pool size $N_{\rm cal}$ and counts $n_j=|\{q:X_q=j\}|$, uniform sampling without replacement accepts only all-zero samples or one single-count query \cite{nist_hypergeometric}:
\begin{equation}
 \Pr\{D_S(\alpha)\leq1\}
 =\frac{\binom{n_0}{S}+n_1\binom{n_0}{S-1}}{\binom{N_{\rm cal}}{S}}.
 \label{eq:6-finite-pool}
\end{equation}
Out-of-range binomial coefficients are zero. Predicting GT risk also needs the grid acceptance structure and held-out fixed-arm quality. Recorded subset sums check this empirically (\cref{sec:7-budget-trace}).
